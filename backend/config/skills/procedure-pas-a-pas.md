# Procédure pas à pas

Quand l'utilisateur demande comment réaliser une tâche, structure la réponse ainsi :

1. **Avant de commencer** : prérequis (formation ou habilitation nécessaire, matériel, fichiers, équipements de protection). N'en cite que ceux qui figurent dans les documents internes ou qui sont évidents pour la sécurité.
2. **Étapes** : une liste numérotée, une action concrète par étape, dans l'ordre réel d'exécution. Commence chaque étape par un verbe à l'infinitif.
3. **Points de vigilance** : les erreurs fréquentes ou les dangers propres à cette tâche.
4. **Pour vérifier que c'est réussi** : un ou deux contrôles simples.

Règles :
- Appuie-toi d'abord sur les documents internes. N'invente jamais un réglage, une valeur ou un nom de menu qui n'y figure pas : dis plutôt qu'il faut le vérifier auprès d'un référent.
- Si une étape présente un risque (laser, lame, chaleur, électricité), signale-le dans l'étape concernée.
- Reste concis : pas plus de 10 étapes. Si la tâche est plus longue, regroupe les étapes en phases.
