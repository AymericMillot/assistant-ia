🚀 Démarrage rapide

De zéro à un assistant fonctionnel en une commande.

Prérequis

  • Une machine Linux (ou macOS) avec au moins 8 Go de RAM et quelques Go d'espace disque libre (davantage selon le modèle d'IA choisi).
  • Docker n'est pas nécessaire au préalable : install.sh l'installe automatiquement sur Debian/Ubuntu s'il est absent.

Installation

cd fablab-ai
./install.sh

Le script installe Docker si besoin, construit les images, télécharge un modèle d'IA adapté à la machine, démarre tous les services, puis crée le compte administrateur initial.

Premier accès

  • Utilisateurs : http://<adresse-du-serveur>:3000
  • Administration : http://<adresse-du-serveur>:3000/admin
  • Les identifiants du compte administrateur initial sont affichés une seule fois à la fin de l'installation.

💬 Utilisation au quotidien

Ce que voient les utilisateurs et ce que gèrent les comptes d'administration.

  • La page d'accueil permet de poser une question en langage naturel ; l'assistant répond en s'appuyant sur les documents indexés.
  • Les échanges ne sont pas conservés après fermeture de la page (confidentialité).
  • Un pouce 👍/👎 sur chaque réponse aide l'assistant à s'améliorer au fil du temps.
  • Une pièce jointe (texte ou PDF) peut être envoyée par un utilisateur pour enrichir le contexte d'une question ponctuelle — l'administrateur peut désactiver cette possibilité depuis l'onglet Pièces jointes.
  • Quand l'assistant n'a ni document interne ni connaissance générale fiable pour répondre, il le dit clairement ("je ne sais pas...") et propose un lien de recherche externe, plutôt que d'inventer une réponse ou de suggérer systématiquement une recherche Internet.

Toutes les commandes se lancent depuis la racine du projet, sur le serveur.

./restart.shRedémarre tous les services.

🗂️ Administration

Accessible depuis /admin, réservée aux comptes autorisés.

Documents

Ajoutez vos fichiers (PDF, Word, Excel, HTML...) depuis l'onglet Documents : ils sont automatiquement découpés, vectorisés et indexés pour la recherche.

Modèles

Changez le modèle de conversation depuis l'onglet Modèles. Les modèles Mistral AI (Mistral, Mixtral, Codestral, Ministral, Devstral, Pixtral, Magistral) sont repérés par un petit drapeau français.

Pièces jointes

L'onglet Pièces jointes permet d'activer ou de désactiver globalement la possibilité pour les utilisateurs de joindre un fichier dans le chat, et de trier (conserver ou supprimer) les fichiers déjà envoyés.

Export et déploiement

La note de version se pré-remplit automatiquement (date, heure, numéro de version) et reste enregistrée dans le navigateur tant que la version n'est pas publiée — vous n'avez jamais besoin d'écrire quelque chose à la main pour publier.

Sauvegarde

Les données vivent dans backend/data (base) et backend/uploads (fichiers). Pensez à les sauvegarder régulièrement si l'instance contient des documents importants.

🩺 Dépannage

Les situations les plus fréquemment rencontrées, et comment les résoudre.

« Ollama n'a pas répondu dans le délai imparti »

Cause la plus fréquente : espace disque insuffisant pour télécharger le modèle. install.sh nettoie automatiquement le cache Docker et s'arrête tôt avec un message clair si l'espace restant est vraiment trop faible. Vérifiez avec df -h et lsblk (un plus grand disque existe peut-être mais n'est pas utilisé).

« Permission refusée » sur le socket Docker

L'utilisateur vient d'être ajouté au groupe docker mais la session n'a pas encore pris en compte le changement. install.sh tente de réactiver le groupe automatiquement (newgrp/sg/sudo -g) ; en dernier recours, déconnectez-vous puis reconnectez-vous.

« node : commande introuvable »

Certains scripts internes appellent Node.js via le conteneur fablab-updater plutôt que sur la machine hôte. Si ce message apparaît, la copie du projet est probablement ancienne — redéployez la dernière archive.

« Permission non accordée » en lisant les scripts

Les fichiers appartiennent à un autre utilisateur (souvent root, après une extraction avec sudo). Reprenez la main avec :

sudo chown -R "$(id -un):$(id -gn)" ~/fablab-ai
« env: opérande supplémentaire » au lancement d'un script

Le fichier a probablement des fins de ligne Windows (CRLF). Corrigez avec :

sed -i 's/\r$//' *.sh
Le port 3000 n'est pas accessible depuis le réseau

Si un pare-feu (UFW) est actif, install.sh ouvre automatiquement le port. En cas d'échec, ouvrez-le manuellement :

sudo ufw allow 3000/tcp
