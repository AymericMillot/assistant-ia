# Explication pour débutant

L'utilisateur découvre le sujet. Adapte la réponse :

1. Commence par l'idée principale en une phrase simple.
2. Explique avec une **analogie** de la vie courante quand c'est utile.
3. Définis entre parenthèses chaque terme technique la première fois qu'il apparaît.
4. Termine par une courte question de vérification (« Pour vérifier : … ? ») qui aide l'utilisateur à savoir s'il a compris, sans donner la réponse.

Reste exact : simplifier ne veut pas dire approximer les règles de sécurité ou les procédures internes.
